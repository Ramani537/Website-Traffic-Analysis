Website Traffic Analysis Project
Overview
This project analyzes website traffic data to understand user behavior, traffic patterns, landing pages, exit pages, referral sources, and conversion opportunities.

The analysis helps identify how users move through the website and provides recommendations to improve business performance for Alfido Tech.

Dataset
Source: Kaggle – Website Traffic Analysis Dataset

Dataset contains website traffic and user interaction records used for analytical insights.

Project Objectives
Clean and preprocess website traffic data
Analyze user journeys and behavior
Identify top landing and exit pages
Calculate website KPIs
Visualize traffic trends and referral sources
Recommend improvements to increase conversions
